# v1.4.0 — Repo families

Date: 2026-11-10 (draft)

## Summary

A maintainer can start a new repo from a family template through a
requirement-driven setup. A maintainer can also move an existing repo to its
family template, so that repos in one family differ only in content and
deploy target.
