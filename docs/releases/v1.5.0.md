# devkit v1.5.0: Flow runs a release end to end

Date: 2026-11-24 (draft)

## Summary

A maintainer runs the flow commands from review to release with no manual
workaround, rerun, or one-at-a-time question stop. This release fixes the
CI, review, and release steps that stop that run today.

## Deployment instructions

1. Optional: in each repo with its own `.claude/settings.json`, replace
   `Bash(flow-plugins:*)` with `Bash(flow-plugins --status:*)` in
   `permissions.allow`. The old rule still works. The new rule makes Claude
   ask before a mode that a later version adds (#141).
2. On each Mac that runs devkit lint, install shellcheck 0.11.0. Check it
   with `shellcheck --version` (#141).
