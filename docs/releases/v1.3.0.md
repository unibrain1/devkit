# devkit v1.3.0: Review trusts only what it should

Date: 2026-10-31

## Summary

A maintainer can trust a green review Gate. Only real human rebuttals and
real review runs count, and no caller, fork, or bot comment can turn the
Gate green.

## Upgrade

- `flow-release-milestone` waits for the required checks of `main` on the
  PR head before it merges (#78). The default limit is 30 minutes.
  `--checks-timeout <minutes>` changes it. `/flow:release-milestone` runs
  the script in the background.
- In a `claude --plugin-dir plugins/flow` session, `flow-release-milestone`
  runs a copy of its `bin` folder from the `--reviewed-sha` commit (#77).
  A run from the work tree with no `--reviewed-sha` stops with exit 1.
  The v1.2.0 command text on `main` runs the script in the foreground,
  and the wait can pass the 10-minute limit. Start the v1.3.0 release
  session on the milestone branch.
- Until the v1.3.0 merge is pulled, `main` has the v1.2.0 script, which
  has no copy step. Before a rerun or a resume of the v1.3.0 release,
  check out the milestone branch, or `main` after it has the merge commit.
